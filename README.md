# Курсовая работа №3.Менеджер управления вакансиями.

## Описание:

Данный проект разрабатывался в рамках курсовой работы и содержит следующий функционал:
1. Функция получения вакасий из API;
2. Функцию создания БД и таблиц; 
4. Функцию заполнения в таблиц;
5. Класс управления вакансиями.


## Установка:

1. Клонируйте репозиторий
   (`git clone`) [GitHub](https://github.com/SuchkovaMaria/Job_search)
2. Установите зависимости
   (`pip requirements.txt`)

## Использование:

1. Откройте проект.
2. Введите данные, запрашиваемые функциями.
